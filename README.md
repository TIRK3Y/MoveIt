# MoveIt

A static, single-page landing page for MoveIt, a fictional moving company. It is a practice project for building a responsive marketing page from Bootstrap 5 components. The navigation links, buttons and postcode search form only look functional: none of them is connected to a back end.

## Features

- Responsive navigation bar with a collapsible menu, a dropdown and a postcode search field
- Hero section with a headline, call-to-action buttons and a feature image
- Three-column "Why Move With Us?" section with SVG icons
- Image carousel with indicators and previous/next controls
- Multi-column footer

## Tech stack

- HTML5
- Bootstrap 5.3 (alpha): the CSS and the JavaScript bundle load from the jsDelivr CDN

## Getting started

No installation or build step is required. Bootstrap loads from the CDN, so the page needs an internet connection.

1. Clone the repository:
   ```bash
   git clone https://github.com/TIRK3Y/MoveIt.git
   ```
2. Open `index.html` in a web browser.

## Project structure

```
MoveIt/
├── index.html   # Landing page markup
├── style.css    # Extra styles (not currently linked from index.html)
├── *.svg        # Icons (brand, features, chevron)
└── *.jpg        # Hero and carousel images
```
